# Design Tokens — Jansen & Vorster

## Colors
| Token | Value | Usage |
|-------|-------|-------|
| `--jv-accent` | `#EB5037` | Banner, icon rings |
| `--jv-cta` | `#ED4524` | Hero CTA button |
| `--jv-text` | `#6F7982` | Body default |
| `--jv-heading` | `#7A7A7A` | Section titles (WHO WE ARE, BRANDS) |
| `--jv-black` | `#000000` | Nav links, feature titles |
| `--jv-feature-bg` | `#F6F6F6` | Features band |
| `--jv-footer` | `#242424` | Copyright bar |
| `--jv-white` | `#FFFFFF` | Page / nav |

## Typography
- **Poppins** 300/400/500 — body, nav, hero title/button
- **Roboto** 500/600 — section headings, icon box titles

## Key sizes (desktop 1440)
- Nav: padding 30px 0 → 15px 0 (scrolled), height 130 → 100
- Hero: 450px tall; title 56px/70px weight 300; CTA 18px/500 padding 12×35 radius 3px
- Important: padding 50px 0, bg `#EB5037`
- Icon circle: 146×146, border 3px solid accent, icon 70px
- Brand logos: 208×208 in 5-column rows
